# Security policy

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub security advisories](https://github.com/octrow/whisper-gpu/security/advisories/new).
You should get a reply within a week.

## Supported versions

Only the latest release gets fixes.

## Scope

In scope: problems in this library's code, for example credentials leaking into logs or exceptions, unsafe
handling of input data, or a dependency with a known vulnerability.
